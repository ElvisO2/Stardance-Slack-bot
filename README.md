# Stardance-Slack-bot
A simple Slack bot built for Hack Club's Stardance program. It sends a daily reminder at seven P M, nudging you to check in on your Stardance progress for the day.

Features: a ping command, called slash stardance ping, to check the bot is alive and responsive, and a scheduled daily reminder message sent as a direct message at seven P M local server time.

Built with Node point J S, Slack Bolt, and Socket Mode. Hosted twenty four seven on Hack Club Nest.
